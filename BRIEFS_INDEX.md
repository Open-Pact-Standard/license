NOTICE. Before v1.4.3 moves from Draft to Published, each jurisdiction a real
adopter might sit in should be confirmed by local counsel. These briefs pre-form
the questions so counsel can confirm/correct efficiently. Each is independently
sendable.*

## Cross-system analysis
`REGIONAL_REVIEW.md` — multi-jurisdiction discrepancy scan (clause × system
matrix, verified/unverified columns).
`LEGAL_REVIEW.md` — adversarial ambiguity review (US-frame contract profile).

## What the briefs share
All use the same 9-section structure: scope → 7 numbered exposures (exact OPL
clause → local statute → question → consequence-if-wrong) → summary table →
"what we need back from counsel." The 7 exposures are constant across systems so
counsel answers are comparable:
1. §5 conditional grant
2. §5 conclusive evidence
3. §1/§3.3 incorporation + burden
4. §7/§8 liability exclusion
5. §12 forum + arbitration
6. §12.1 urgent relief
7. §3.3 good faith

## Gate before publish
OPL v1.4.3 stays **Draft** until: (a) local counsel confirms each jurisdiction's
#1 (self-executing grant) and #3 (AGB/unfair-terms posture) — the two
substance-bearing questions; (b) Brazil sub-article numbers are verified; (c)
maintainer sign-off on timing + content. No tag/release without explicit
approval.
